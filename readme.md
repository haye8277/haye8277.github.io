# kneejar.com

Jacob Hayes's personal site: a Jekyll site served by GitHub Pages from the `master` branch.

- Pages: `index.html`, `about.html`, `projects.html`, `blog.html`, `404.html`
- Posts: `_posts/`
- Styles: `css/main.scss` pulls in `_sass/_theme.scss` (colour tokens, light and dark), `_sass/_base.scss` and `_sass/_layout.scss`
- Shared pieces: `_includes/` (header with the JH monogram, footer, the little ships and hand-drawn bits)

The monogram, favicon and social card are generated from the same pen-drawn JH.
